# The Twelve Tables in Akoma Ntoso

Rome's Twelve Tables, in P.R. Coleman-Norton's English reconstruction, in Akoma Ntoso XML with a bronze-style CSS rendering. It was generated by Claude for Grant Vergottini.

The original tables are lost. The text survives only through later writers, so this is one modern editor's arrangement and translation, not an original document.

## Files

| File | Purpose |
| --- | --- |
| `twelve-tables.xml` | The Akoma Ntoso document |
| `twelve-tables.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Structure:** Twelve `hcontainer name="table"` elements hold 107 `hcontainer name="fragment"` elements, followed by one unplaced fragment. Table placement and order follow the editor; many attributions are uncertain.
- **Editorial completions:** Words the editor placed in square brackets to complete the sense are in `<span class="supplied">`.
- **Definitions and translations:** Words in parentheses are in `<span class="gloss">`.
- **Gaps:** Ellipses are marked with `<omissis>`.
- **Notes:** The editor's notes 5 to 75 are in `<notes>` in the metadata, referenced by `<noteRef>`. The stylesheet displays them after the tables. Notes 1 to 4 belong to his introduction, which is not included.
- **Dates and jurisdiction:** The work date, `-0449-01-01`, stands for the traditional year 449 BCE; the month and day are placeholders. The jurisdiction code `rome` is not a standard country code. The expression date is the Project Gutenberg release, because that text gives no publication date.
- **Latin:** The document is English only. `FRBRtranslation` records that the text is translated from Latin, but no Latin expression is included.

Unbracketed text is not necessarily an original quotation. According to the editor's introduction, the surviving fragments range from near-original wording to later paraphrase and interpretation. The markup does not classify each fragment by those types or record its ancient source.
